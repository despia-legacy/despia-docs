Play Lottie animations in your screens, such as onboarding art, empty states and success moments.

Adds a lottie element you place in your layout with a link to a Lottie JSON file or a bundled animation name. You can set looping, speed and autoplay, and react when it finishes. The web version pauses on the first frame for people who prefer reduced motion. Needs an animation exported as Lottie JSON.

Open package. License: Apache-2.0. Version 0.1.0.

## When to use it

Use it when you want a vector animation, such as onboarding art, an empty state or a success moment, exported as Lottie JSON. For video or large images use another media element.

despia add Core/Lottie
