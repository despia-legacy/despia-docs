The built-in set of screen building blocks every DSX app uses.

Foundation provides the components behind the markup you write: stacks, text, images, buttons, inputs, lists, grids, tabs, sheets, forms and the video element, along with the renderers that turn a route into a screen. It is always part of your app and cannot be removed. There is nothing to call; you use it every time you write a screen.

Open package. License: Apache-2.0. Version 0.1.0.

## When to use it

You never choose it, because every app includes it. Read about it when you want to know which building blocks are available for a screen. Look at the Core packages when you need device features rather than layout.

## Install

```sh
despia add Mandatory/Foundation
```
