Show your web pages inside the app in one shared web view.

The web view component the app surface mounts.

Commercial package. License: Despia-Commercial-Source-1.0. Version 0.1.0.

## When to use it

Use it whenever a screen of your app is a web page, since it is the web view the app shell mounts for the default route. Give it a name when you need a second web view beside the main page, for example a sheet that shows your terms page. Skip it for screens that are built from native components.

## Install

```sh
despia add Core/Dom/Components/Views/DSXWebView
```

A commercial package: it is added the same way, and the build checks your plan includes it.
