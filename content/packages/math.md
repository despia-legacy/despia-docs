Show math formulas, written in TeX, as properly typeset equations in your app.

Draws formulas in markdown text, inline with $...$ or as a centred block with $$, as real typeset math instead of raw TeX source. Use it for study, science or finance content. On iOS it adds the SwiftMath typesetter and about 7 MB of math fonts; the web already shows math with the browser's own layout. Android is not covered yet.

Open package. License: Apache-2.0. Version 0.1.0.

## When to use it

Use it when your markdown shows formulas written in TeX, such as study, science or finance content. Skip it if your app never shows math, since it adds about 7 MB of fonts on iOS.

## Install

```sh
despia add Core/Math
```
