A video player element you place in a screen and drive from state.

Provides the video element for playing a file or stream in your app, using the system player on each platform. You control source, autoplay, looping, muting, speed and fit with plain properties, and bind pause state and playback position to your own variables. It reports ready, play, pause, end, progress and error events.

Open package. License: Apache-2.0. Version 0.1.0.

## When to use it

Use it whenever a screen needs to play a video that stays inside your layout, such as a hero clip or a lesson. For audio only, or full media composition and export, use the audio and media packages instead.

## Install

```sh
despia add Mandatory/Foundation/Components/Media/Video
```
