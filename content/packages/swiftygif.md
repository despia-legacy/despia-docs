Add the SwiftyGif library so iOS apps can play animated GIF images.

A building block for iOS: it adds the SwiftyGif library to your app build and nothing else. It has no actions or markup of its own, so you will not see it in your screens directly. Include it only if another part of your app or a package asks for it.

Open package. License: Apache-2.0. Version 0.1.0.

## When to use it

Add it only if another part of your app or a package asks for it, to play animated GIFs on iOS. It does nothing by itself and has no web or Android part.

## Install

```sh
despia add Core/SwiftyGif
```
