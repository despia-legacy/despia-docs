Show announcements in your app as a dismissible banner and a What's new list.

Reads a feed that you own and shows the newest announcement as a banner the user can close, plus the full list as a What's new screen. Closed announcements stay closed on that device. You publish the feed and choose where the banner and list appear; nothing is shown when the feed is empty.

Open package. License: Apache-2.0. Version 0.1.0.

## When to use it

Use it to tell users about new features, maintenance or incidents without shipping an update. If you only need a one-off message at launch, a simple alert is enough.

## Install

```sh
despia add Core/Announcements
```
