# Universal attributes

Every element in the library carries all of these, so no component page repeats them. They are the reason a component page's attribute table is short: it lists only what that element adds.

|---|---|---|---|
| `a11yGroup` | `bool` |  | Children combine into one accessibility element. |
| `a11yHidden` | `bool` |  | Invisible to assistive tech (decorative). |
| `a11yHint` | `string` |  | Supplemental, read after a pause. |
| `a11yLabel` | `string` |  | What assistive tech reads aloud. |

| `animationCurveDuration` | `number` (s) |  | Duration in seconds for animationCurve. |
| `as` | `string` |  | The ROW NAME of a repeater (proposals/nested-data.md, approved 2026-09-30): on an element carrying `repeat=`, or on `<list>`/`<grid>`/`<pager>`/`<flow>` carrying `bind=`, an identifier that names that repeater's rows for their descendants, read as `dsx.this.ancestor('name')`: the nearest enclosing row with that name, never the current row. Resolved when the document is read, to the `parent` chain, so a wrapper or a restyle cannot change what a name means. One name per document (row-name-ambiguous); never `this`, `parent`, `index`, `value` or `ancestor` (row-name-invalid). READ IN THOSE PLACES ONLY, the way `key` is: on slot content `as` stays the scoped-slot binding (ADR 0020), and on the declaration tags it is their own attribute. |

The control stays the system control and authored CSS still wins per property. Exact lowercase after trim; anything else is NO PIN (the nearest resolving ancestor wins); unset, regular. On one element with density, controlSize decides the control size. Interpolates. Law: Conformance/input/control-size.json. |

Web derives every control metric from the density token tables (data-dsx-density); iOS maps the pin onto the system controlSize environment; Android's resolution is corpus-gated in :core with the Compose presentation pinned as a deferral (M3 ships no control-density system). Interpolates. Law: Conformance/input/density.json. |

A document that declares none reads as the OLDEST version the runtime knows, never the newest. A version the runtime does not speak refuses the document and names every version it does. |

Declaring it TAKES the menu request over this element: the web listener preventDefaults, so the browser's own menu does not open over a surface that draws its own. An element that declares none is never listened to and keeps the native menu. It is one channel for two gestures, because the browser already unifies them: a right click or a two finger click on a pointer, and a long press on touch, both arrive as one contextmenu. They are always present and false where no keyboard exists (touch, a screen reader activation, a watch or TV press), every activation carries them (a pointer click, Enter or Space on a focused tappable, an href link, a shortcut= firing, which reports the chord's own flags), and they win over a row field or an arg:* of the same name. ## Conventions

**units.** Lengths are points (pt) on iOS, the same numeric value as dp on Android.

**booleans.** Serialized as the strings "true" / "false".

**interpolation.** Any attribute value may contain {{ expr }} (JSE) and bind to the store - a panel can expose a per-field bind escape hatch.

**unknownAttributes.** Ignored by the engine (graceful degradation).

**platformSuffix.** Any attribute key may carry an exact :ios / :android / :web / :watch / :wear / :macos / :windows / :linux suffix, or the :desktop / :native group suffix. Precedence is exact > :desktop > :native > bare.

**argPrefix.** arg:`<key>`="value" attributes assemble a typed payload for dsx.event handlers (`dsx.send` is retired; the linter names it, `dsx-send-retired`). type:`<name>`="`<shape>`" (PROPOSED, proposals/types-on-declarations.md Decision 2) types ONE NAME a declaration already declares: an input:`<name>` of an `<action>` or a `<formula>`, or a payload= name of an `<event>`, with the shape grammar of conventions.declarationTypes. A prefix needs no list, so it has no attribute row; a type:`<name>` naming nothing the block declares is the linter's type-unknown-word.

**componentEvents.** A component invocation accepts on:`<event>` for every event its definition declares (events bubble to the nearest consumer).

**styleAttribute.** style="…" holds inline DSX-CSS declarations or named classes; the universal style vocabulary lives in styleProperties ($ref), not per element.
